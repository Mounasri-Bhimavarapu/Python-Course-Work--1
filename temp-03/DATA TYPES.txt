DATA TYPES
  
   Data types are the types that a value is stored by variables
types

  1.NUMERICAL DATA TYPES
    A.INTEGER(int):Stores numerical values
    B.FLOAT: Stores decimal values
    C.COMPLEX: Stores real and imaginary values (2+i)
  2.SEQUENTIAL DATA TYPES
    A.STRING(str):Collection of characters enclosed within single or double quotations
                  PROPERTIES: Immutable
                             Duplicates allowed
                             Ordered
   B.LIST(list):Collection of elements enclosed in square braces
                PROPERTIES: Mutable
                            Duplicates are allowed
                            Dynamically sized
                            Ordered
                            Heterogeneous
  C.TUPLE(tuple):collection of elements enclose with in parentheses()
                PROPERTIES: Immutable
                            Duplicates are allowed
                            Ordered
                            Heterogenous
                            Fixed size
 3.MAPPING DATATYPE: We have 
     A.SET: Collection of elements that are enclosed with in a curly braces{}
           PROPERTIES: Mutable
                       Dynamically sized 
                       Duplicates are not allowed
                       Heterogenous
                       Unordered
            FROZEN SET: Form of set that does not allow duplicates
    B.DICTIONARY: Collection of elements enclosed with in curly braces
                 PROPERTIES: Mutable
                             Ordered
                             Dynamically sized
                             Heterogeneous
4.BOOLEAN VALUE: Consists of true/false
5.NONE TYPE: Used to create an empty set
