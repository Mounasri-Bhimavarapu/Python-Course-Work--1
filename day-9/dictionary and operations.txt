DICTIONARY:COLLECTION OF KEY-VALUE PAIRS ENCLOSED WINTHIN IN CURLY BRACES{}
PROPERTIES:KEYS- Should be immutable and unique(does not allow set ,dictionary ,list as key)
          :VALUES- can be mutable or immutable and duplicates are allowed.
          :ordered
          :heterogeneous
OPERATIONS:1.Membership
           2.Direct access using keys
           3.using var.get()- generally used in order to avoid keyerror
           4.len()
           5.max()
           6.min()
           7.sorted()
           8.copy()
           9.var.setdefault()
          10.fromkeys()-used when we need to assign same value for all keys
MODIFICATION METHODS:1.var[key]=value
                    2.var.update(key:value)
                    3.var.popitem()-delete last key-value pair
                    4.var.pop(key)- to remove particular key-value pair
                    5.del var[]
                    6.var.clear()
