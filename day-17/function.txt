FUNCTION: It is a reusable block of code used for a specific task.

ADVANTAGES:
           1.MODULARITY: large programm is divided into small units to perform task easily.
           2.Easy Debugging: errors can be resolved easily within a function.
           3.Code reusability: function can be used without writing same code multiple times.
           4.Acepts inputs: function accepts parameters and gives required output.
           5.Saves time: once function is ceated it can be used multiple times.
           6.Easy maintainance: changes in one module can be made with out disturbing entire program.
           7.Easy readability: function helps us in understanding programm clearly.
