PYTHON OPERATORS
       
       1. ARTHEMATIC OPERATORS: 
        
               a. addition(+)
               b. subtraction(-)
               c. multiplication(*)
               d. division(/)
               e. floor division(//)
               f. modulus(%)
               g. exponent(**)
      2. COMPARISION OPERATORS:
               
              a. >
              b. <
              c. >=
              d. <=
              e. ==
              f. !=
      3. ASSIGNEMENT OPERATORS:
        
             a. +=
             b. -=
             c. *=
             d. **=
             e. //=
             f. /=
      4. LOGICAL OPERATIONS:
       
             a. and - true if all conditions are true
             b. or  - true if any one of condition is true
             c. not - results true if false, false if true
      5. MEMBERSHIP OPERATIONS:
         
             a. in -if it is present in data
             b. not in -if it is not present in data
      6. IDENTICAL OPERATIONS:
   
             a. is - refers to same id object reference
                a=[1,2,3]
                b=[1,2,3] these are not identical they share  different id (memory location)
                 a=c, here a,c are identical they share same id
             b. is not - refers to having different id
      7. BITWISE OPERATORS:
           
             & - 11=true,00=true
               - 01,10=false
             | -11,01,10=true
               -00=false
             ^ -11=0,00=false
               -10,01=true
             >> - remove zeroes
             << - add zeroes at end

print(a,b,c,sep='')

if we want to end with something then
print('a=',a,'b=',b,'c=',c,end='@')
