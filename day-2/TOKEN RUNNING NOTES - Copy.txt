TOKEN

   Token is a smallest unit of a program .It has 5 components:
  1.IDENTIFIERS-These are the names of functions,variales,packages,modules
  2.OPERATORS-These contains arthematic, logical,membership,bitwise,
  3.LITRALS-values
  4.KEY WORDS-These are the predefied terms{if ,else ,}
  5.PUNCTUATORS-These includes @ ,space()

identifier-rules

   1. Identifier contains uppercase ,lowercase ,digits ,_
   2. No special characters are allowed[@]
   3. Starts with uppercase ,lowercase ,_
   4. Can not start with digits
   5. Case sensitive
